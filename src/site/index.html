从配置到现场闭环

MDKOSS 把驱动插件、设备组件、任务调度、变量中心与 HTTP/CEF 监控收成一条可运行链路。机型差异主要落在 JSON 与少量扩展代码，而不是从零搭运动与 HMI。

配置流程

一份 setting.json 描述整机。离线用 Config.Wpf 编辑，启动时按 变量 → 驱动 → 设备 → 任务 实例化；改驱动或设备后需重启运行时。

  1. 1

    写工程

    Config.Wpf 或直接改 JSON：工程名、监控端口、启动页。

  2. 2

    挂硬件

    drivers 选 sim / gts / dmc，再配 GPIO、轴与平台。

  3. 3

    编排动作

    tasks 写周期任务，recipes 管换型参数，vars 给初值。

  4. 4

    运行观测

    加载配置启动宿主，CEF / 浏览器监控、点动与调试。
